# 認証レベル・権限マトリクス

## 認証レベルと会員

| レベル | 条件 | 主な許可 |
|---|---|---|
| L0 | 未認証 | 公開案内、公開トレンディ |
| L1 | メール検証・規約同意 | プロフィール下書き、興味設定 |
| L2 | SMS検証 + 18歳自己申告 | 投稿、コメント、スレッド、参加、マイフレ申請 |
| L3 | 年齢確認 | 1対1メール、交換日記、出品、コミュニティ作成 |
| L4 | 必要時eKYC | 企業管理、高リスク復帰等 |

SMSは年齢確認ではない。認証事業者と年齢確認方式は未決定である。

会員区分はゲスト、無料会員、既存仕様の有料会員、公式会員（企業公式コミュニティ）を分離する。有料会費、公式会員条件、IAP/Stripe方式は確定しない。

## 操作判定

| 操作 | 許可条件 | 拒否条件 |
|---|---|---|
| 公開閲覧 | L0以上 | 非公開対象、停止状態の対象データ |
| 投稿/コメント | L2 + active + レート内 | L0/L1、停止、連投・日次上限、ブロック関係 |
| スレッド参加 | L2 + active | 停止、満員、期限切れ、上限超過 |
| コミュニティ発言 | L2 +参加後の待機条件 | 未参加、待機期間中、停止 |
| マイフレ申請 | L2 + active + 日次/人数上限 | block、上限、停止 |
| 1対1メール/交換日記 | L3 + 許可された関係 | L2以下、block、受信設定拒否、停止 |
| 出品/コミュニティ作成 | L3 +承認済み条件 | 条件未確定中、停止 |
| 管理操作 | admin/staff + MFA +担当範囲 | community manager、通常ユーザー、MFA不成立 |
| 公式会員操作 | 公式会員 +対象community権限 | 他community、通常会員、停止 |

## 状態・関係による上書き

`active`は通常評価、`ai_suspended`はログインと異議申立てを残し通常投稿・交流を承認済みポリシーに従い制限、`suspended`は法的に必要な窓口以外を拒否、`banned`は明示的窓口以外を拒否する。AIだけで正式停止へ遷移させない。

blockはプロフィール相互作用、申請、メール、日記、通知、投稿相互作用を双方から遮断する。マイフレ関係があってもblockが優先する。通報はアクセス制御ではなく案件化と監査である。無料/有料による上限差は正式承認済みの値だけをサーバーで適用し、端末入力を信頼しない。
