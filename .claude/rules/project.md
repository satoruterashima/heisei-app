# プロジェクト固有ルール

一次情報源は `資料/V2/HEISEI_企画要件定義_基本設計書_v2.0.docx` と `資料/V2/HEISEI_会員ワークフロー仕様書_v2.0.docx`。数値や条件を実装する前に、本ファイルの記載と一次資料に食い違いがないか確認すること。未決定・要確認と記した項目は、ユーザーへの確認なしに独自の値で実装しない。

## 1. 表記・トーンのルール

* セクション名は必ず「本日のトレンディ」を使用する。「今日のトレンディ」は誤記。
* コアUI（見出し・ボタン・コンポーネント見本・初期コミュニティ名など運営が用意する文言）で「平成」「懐かしい」「あの頃」「エモい」を常用しない。ユーザー投稿文中の自然な使用は制限しない。
* 外部向け広告・LP・ストア掲載文では「平成をテーマにしたSNS」という説明は可。ただしサービス内表現とは分離し、混同しない。
* コミュニティ名は自然な参加しやすい名称にする。
  * 良い例：アニメ好き集まれ／音楽好きの部屋／ライトノベル読書会／ゲーム雑談部／写真・カメラ部
  * 悪い例：「平成〇〇好き集まれ」のように「平成」を冠する名称
* ロゴのフルロックアップ（「あの頃と、つながるSNS。」付き）はLP・販促物専用。アプリ内ヘッダーはタグラインなしのショートロックアップ（カセットアイコン＋wordmarkのみ）を使用する。

## 2. サービス定義

* 対象年齢：18歳以上。
* 目的：オンライン交流。外部で会う約束、連絡先交換、恋人募集、送金要求は禁止。
* 主要機能：141文字投稿、スレッド、コミュニティ、マイフレ、交換日記、メール、足あと、キリ番、本日のトレンディ、着せ替え。

## 3. 会員区分・段階認証

| 区分 | 名称 | 料金 |
|---|---|---|
| 未登録 | ゲスト | 無料 |
| 無料会員 | マイフレメンバー | 無料（広告あり） |
| 有料会員 | マイフレ会員 | 月315円（広告なし） |
| 企業 | 公式コミュニティ | 月5,000円 |

| 認証レベル | 条件 | 解放機能 |
|---|---|---|
| L0 | 未登録 | サービス紹介、公開トレンディ等 |
| L1 | メール認証 | プロフィール下書き、興味設定 |
| L2 | SMS認証＋18歳以上自己申告 | 投稿、コメント、スレッド、コミュニティ参加、マイフレ申請、有料登録 |
| L3 | 年齢確認 | 1対1メール、交換日記、アイテム出品、コミュニティ作成、風紀委員 |
| L4 | 本人確認/eKYC（必要時） | 企業管理、重大違反後の復帰、高リスク操作 |

**全員一律のeKYC必須は採用しない。** SMS認証はスパム対策であり年齢確認ではない。年齢確認方式・対象機能は公開前に弁護士レビューで最終確定する。

個別メッセージ受付は性別ではなく関係性（マイフレのみ／同じコミュニティ／誰からでも／受け付けない）で制御する。性別項目自体をプロフィールに残すかは未決定。

## 4. 本日のトレンディ

* 対象期間：1989年〜2006年。
* その日の同月同日に該当する年を**1日1つだけ**ランダムに選び、表示するトピックはすべて同じ年から取る（異なる年のトピックを同時に並べない）。
* ホームでは2行のみ表示、詳細画面でカテゴリ別に展開。
* AIに事実を創作させない。出典を保存する。生成は1日1回、全ユーザー共通。

## 5. スレッド

* 同時稼働最大1,000スレッド、最大10,000レス。
* 稼働数に応じた自然消滅ルール（1〜100は無期限、101以降は稼働数が増えるほど短縮、901〜1,000は1時間）。詳細な時間割は基本設計書を参照。
* ksk（延長）は1回15分。無料会員1時間1回、有料会員1時間3回。
* 同一ユーザーの連続投稿・連続コメントは3回まで。

## 6. コミュニティ

* 参加後3日間は閲覧のみ、3日後に投稿・コメント・イベント参加を解放。
* 初期参加枠3、追加枠は100コインで1枠、暫定最大10。
* **【要確認】コミュニティ作成条件**：メモ上の決定事項では「有料会員として3か月以上継続」等の条件が想定されていたが、v2.0会員ワークフロー仕様書ではL3（年齢確認）のみが条件として記載されている。実装前に正式条件をユーザーに確認すること。
* レベルは無限に増加する（100で打ち止めにしない）。レベル90称号「番長」、レベル100称号「バリバリ最強NO.1」、レベル101以降は永続的に上昇し隠し称号・追加報酬を検討（詳細未決定）。
* レベル10ごとにコミュニティ名入り背景・衣装・フレーム・バナー・便箋・スタンプ等を付与。
* 経験値は会話・アクティブ人数・交流の多様性・継続日数・イベント参加・有料会員活動を総合評価する。有料会員関連の評価比率は最大20%程度に抑え、有料会員数だけでレベルが上がらないようにする。

## 7. マイフレ・メール・交換日記

* マイフレは相互承認制。申請は1日10人まで、最大1,000人。ブロックで解除。
* メールは無料会員はチケット制・1日10通。有料会員はチケット不要で1日10通。
* メール上限リセット：300コインで**1日1回だけ**、追加10通、1日最大20通。繰越不可。
* 交換日記：L3必要、最大50人、相手ごとに1日1回、既読時刻は表示しない、返信期限なし。同時利用人数はマイフレ人数の1/5（端数切り上げ、最大50人）。

## 8. 課金・コイン

| 価格 | 付与コイン |
|---|---|
| 300円 | 300 |
| 500円 | 520 |
| 1,000円 | 1,100 |
| 2,000円 | 2,300 |
| 3,000円 | 3,600 |
| 5,000円 | 6,250 |

* 購入コイン有効期限1年、配布コイン有効期限3か月。退会時に全失効。
* 購入コインと配布コインは別台帳で管理し、残高を直接書き換えない（台帳＋ロット方式）。
* ユーザー間送金不可、現金化不可。
* アイテム価格は50〜1,000コイン。制作者へは販売価格の50%を配布コインで付与。
* 有料会員は月3回まで出品可、無料会員は出品チケットが必要。

## 9. 安全・モデレーション

* 電話番号・URL・SNS ID・待ち合わせ・金銭・脅迫・性的表現等はルール判定し、危険候補のみAIへ送る。重大処分は人間が最終判断。
* 風紀委員は削除・停止権限を持たない。定型文の「注意札」のみ使用可（自由文不可）。
* 誤審が1回でもあれば1か月間、注意札権限を停止。悪質な場合は永久解除。注意札は投稿者本人に通知し、処分履歴にはしない。複数注意札はAI確認対象とする。
* **【要確認】広告の表示頻度**：ホーム8投稿ごと・一覧10件ごと・スレッド詳細100レスごと等の具体的な数値は会話上の決定事項として存在するが、v2.0資料には定性的な配置ルール（タイムライン・一覧・長いスレッド末尾等、メール/交換日記/入力/通報/決済/安全警告には出さない）のみが反映されている。実装前に数値を確定させること。
* 広告は無料会員のみに表示、有料会員は原則非表示。

## 10. 休眠・退会

* 休眠：最終ログインから1年で新規個別交流を停止し、復帰認証を要求。
* 完全削除：休眠から3か月で個人情報削除・関係解除・コイン失効。
* 決済・不正対策等の法定記録は必要期間のみ分離保管。

## 11. 未決定・要確認事項（実装前にユーザー確認が必要）

* 正式な先行登録開始日、先行登録特典の配布条件・期限（販促物に記載された「2025/06/01」は現在の資料日付より過去であり、そのまま採用不可）
* 年齢確認事業者・SMS認証事業者の選定
* 性別項目をプロフィールに残すか、性別での受信制限を完全廃止するか
* レベル10〜80のコミュニティ称号、レベル101以降の報酬ルール
* 先行登録テーマの正式名称（仮称「FIRST WAVE」）
* 公式初期アイテムの点数・アイテム制作ガイドライン
* 休眠削除前の通知回数
* 企業公式コミュニティの機能範囲
* コメント返信階層（v2.0資料は「1階層」と確定表記だが、画面仕様段階での再確認が推奨されている）
* マイフレ再申請禁止期間

これらに依存する機能を実装するエージェントは、着手前に必ずユーザーに確認を取ること。
